# Лабораторная работа 1. Регрессия

Предсказание качества красного вина по его химическим характеристикам (датасет Wine Quality с UCI). Задание лежит в lab01.pdf, решение в ноутбуке lab01_regression.ipynb.

## Данные

Датасет красного вина: 1599 записей, 11 признаков (кислотность, сахар, хлориды, SO2, плотность, pH, сульфаты, алкоголь) и целевая переменная quality - оценка по шкале от 0 до 10, но в данных встречаются только оценки от 3 до 8. CSV лежит в папке data, если его нет, ноутбук скачает данные сам.

## Что сделано

- удалены дубликаты (240 строк) до разбиения на train и test, чтобы одинаковые вина не попали в обе выборки
- разбиение 80/20 со стратификацией по quality
- EDA на обучающей выборке
- обучены baseline (среднее по train), Ridge (со StandardScaler, alpha подбирался по кросс-валидации), Random Forest и Gradient Boosting
- модели сравнивались по кросс-валидации на train (5 фолдов), тест использовался только для итоговой оценки
- разобраны важность признаков и ошибки лучшей модели

## Результаты на тесте

| Модель | RMSE | MAE |
|---|---|---|
| Random Forest | 0.626 | 0.480 |
| Gradient Boosting | 0.634 | 0.496 |
| Linear Regression (Ridge) | 0.655 | 0.511 |
| Baseline | 0.819 | 0.692 |

Лучше всего получился случайный лес, порог RMSE < 0.70 пройден. Самые важные признаки у всех моделей - alcohol, sulphates и volatile acidity. Хуже всего модель предсказывает редкие оценки (3, 4 и 8), потому что таких вин в данных очень мало.

## Запуск

Нужны numpy, pandas, matplotlib, seaborn, joblib и scikit-learn (версия 1.4 или новее). Ноутбук запускается целиком через Run All, обученная модель сохраняется в model.joblib.
