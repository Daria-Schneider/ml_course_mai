Полный цикл решения задачи регрессии: анализ данных, baseline, обучение и честное сравнение нескольких моделей, анализ важности признаков и ошибок.

- Задание: [lab01.pdf](lab01.pdf)
- Решение: [lab01_regression.ipynb](lab01_regression.ipynb)

## Задача

По физико-химическим характеристикам красного вина предсказать его оценку качества `quality` (оценка дегустаторов по шкале 0-10). Целевая переменная числовая, поэтому это задача регрессии.

- Основная метрика: **RMSE**, требуемый порог **RMSE < 0.70**
- Дополнительная метрика: **MAE**

## Данные

[Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality) (UCI Machine Learning Repository), красное вино Vinho Verde.

- 1599 вин, 11 числовых признаков: кислотность (`fixed acidity`, `volatile acidity`, `citric acid`), сахар, хлориды, свободный и общий SO2, плотность, pH, сульфаты, алкоголь
- целевая переменная `quality`: значения от 3 до 8, сильный дисбаланс (оценки 5 и 6 - около 82% вин)
- копия данных лежит в `data/winequality-red.csv`; если файла нет, ноутбук скачает его с UCI автоматически

## Что сделано

1. **Первичный осмотр данных.** Пропусков нет, все признаки числовые, масштабы признаков сильно различаются.
2. **Обработка дубликатов.** Найдено 240 полных дубликатов (15% строк). Они удалены до разбиения на train/test, чтобы одно и то же вино не попало одновременно в обе выборки. Без удаления у 24% тестовых вин была бы точная копия в train. Осталось 1359 вин.
3. **Разбиение.** Train/test 80/20 (1087 и 272 вина) со стратификацией по `quality`, чтобы редкие оценки были представлены в обеих выборках.
4. **Исследовательский анализ (только на train).** Распределение целевой переменной, распределения признаков и выбросы, корреляции с `quality` (Пирсон и Спирмен), корреляции между признаками.
5. **Схема эксперимента.** Все решения (подбор `alpha`, выбор лучшей модели) принимаются по 5-fold кросс-валидации на train, на одинаковых фолдах для всех моделей. Test используется один раз - для финальной оценки.
6. **Модели:**
   - Baseline - константа, равная среднему `quality` на train
   - Linear Regression - `Pipeline(StandardScaler, Ridge)`, `alpha` подобран через `GridSearchCV`
   - Random Forest Regressor
   - Gradient Boosting Regressor
7. **Важность признаков.** Коэффициенты Ridge, MDI у деревьев, permutation importance; сравнение моделей между собой и с результатами анализа данных.
8. **Анализ ошибок лучшей модели.** Распределение ошибок, качество для каждого значения `quality`, разбор вин с самыми крупными ошибками.
9. **Модель для новых данных.** Функция `predict_quality` и сохранённая модель `model.joblib`.

## Результаты

Метрики на тестовой выборке:

| Модель | RMSE | MAE |
|---|---|---|
| **Random Forest** | **0.626** | **0.480** |
| Gradient Boosting | 0.634 | 0.496 |
| Linear Regression (Ridge) | 0.655 | 0.511 |
| Baseline (mean) | 0.819 | 0.692 |

Лучшая модель - **Random Forest**: выбрана по кросс-валидации (CV RMSE 0.644), на test RMSE = 0.626, что ниже порога 0.70.

## Выводы

- Все три модели превзошли baseline (RMSE ниже на 20-24%) и проходят порог.
- Ансамбли деревьев работают лучше линейной модели: в данных есть нелинейные зависимости и взаимодействия признаков, которые линейная модель не учитывает.
- Самые важные признаки во всех моделях - `alcohol`, `sulphates` и `volatile acidity`, что совпадает с результатами анализа данных. Важность признака показывает статистическую связь, а не причину изменения качества.
- Модель хорошо предсказывает массовые оценки 5 и 6 (MAE около 0.4), но заметно хуже редкие оценки 3, 4 и 8: таких вин мало, и прогнозы смещаются к среднему значению.
