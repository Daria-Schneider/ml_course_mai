# Лабораторная работа 3. Оптимизация гиперпараметров

Подбор гиперпараметров Gradient Boosting для задачи из лабораторной работы 2 (выживание пассажиров Титаника, датасет Titanic Dataset с Kaggle). Задание лежит в lab03.pdf, решение в ноутбуке lab03_hyperparameters.ipynb.

## Данные и модель

Данные, признаки и разбиение такие же, как в лабораторной 2: 891 пассажир, 9 признаков (7 исходных, Title и FamilySize), train 712 / test 179 со стратификацией и random_state=42. Метрика - F1 для класса "выжил". CSV лежит в папке data, если его нет, ноутбук скачает данные сам.

Baseline - Gradient Boosting с параметрами из лабораторной 2: 200 деревьев, learning_rate 0.05, max_depth 3.

## Что сделано

- подбирались три гиперпараметра: n_estimators (50-800), learning_rate (0.01-0.3), max_depth (1-6)
- все решения принимались по кросс-валидации на train (5 фолдов, StratifiedKFold), тест использовался один раз в конце
- Grid Search по сетке из 100 комбинаций (5 x 4 x 5)
- Random Search с тем же бюджетом (100 комбинаций из непрерывных распределений), сравнение с Grid Search по качеству, числу комбинаций и времени
- построены кривые качества на train и CV по каждому гиперпараметру и тепловые карты, найдены области недообучения и переобучения
- анализ устойчивости: результаты по отдельным фолдам и проверка выбранных моделей на 10 других разбиениях train на фолды

## Результаты

| Модель | Деревья / шаг / глубина | CV F1 | Test F1 |
|---|---|---|---|
| Baseline | 200 / 0.05 / 3 | 0.744 | 0.746 |
| Grid Search | 100 / 0.3 / 1 | 0.771 | 0.756 |
| Random Search | 180 / 0.283 / 1 | 0.771 | 0.774 |

Оба поиска нашли одну и ту же область - деревья глубины 1 с большим шагом. Random Search дал то же качество, что Grid Search, и подошёл к лучшему результату уже за 10-20 итераций.

Прирост от подбора оказался ненадёжным. На 10 других разбиениях train подобранные модели не лучше baseline (0.756 против 0.769), а на тесте у всех трёх моделей примерно одинаковое число ошибок (31-33 из 179). F1 у подобранных моделей выше в основном потому, что они чаще отвечают "выжил". Параметры baseline уже были близки к оптимальным, и на этом датасете подбор гиперпараметров качество заметно не улучшает.

## Запуск

Нужны numpy, pandas, matplotlib, seaborn, scipy, joblib и scikit-learn (версия 1.4 или новее). Ноутбук запускается целиком через Run All (около 5 минут), лучшая модель Grid Search сохраняется в model.joblib.
