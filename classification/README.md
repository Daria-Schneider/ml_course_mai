# Лабораторная работа 2. Классификация

Предсказание выживания пассажиров Титаника (датасет Titanic Dataset с Kaggle). Задание лежит в lab02.pdf, решение в ноутбуке lab02_classification.ipynb.

## Данные

891 пассажир, целевая переменная Survived (1 - выжил, 0 - погиб), выживших около 38%. Признаки: класс билета, пол, возраст, число родственников на борту, цена билета, порт посадки, а также имя, номер билета и каюта. CSV лежит в папке data, если его нет, ноутбук скачает данные сам.

## Что сделано

- убраны идентификаторы (PassengerId, Name, Ticket) и Cabin (77% пропусков); из имени взято обращение (Title), добавлен размер семьи (FamilySize)
- разбиение 80/20 со стратификацией по Survived
- EDA на обучающей выборке
- пропуски и категории обрабатываются внутри Pipeline только по train, для SVM и KNN добавлено масштабирование
- обучены baseline (самый частый класс), Decision Tree, Random Forest, Gradient Boosting, SVM и KNN; глубина дерева и число соседей подбирались по кросс-валидации
- модели сравнивались по кросс-валидации на train (5 фолдов), для моделей с подбором параметра - вложенная кросс-валидация; тест использовался только для итоговой оценки
- разобраны важность признаков (MDI и permutation importance) и ошибки лучшей модели

## Результаты на тесте

| Модель | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| SVM | 0.838 | 0.812 | 0.754 | 0.782 |
| Decision Tree | 0.832 | 0.800 | 0.754 | 0.776 |
| Random Forest | 0.838 | 0.845 | 0.710 | 0.772 |
| Gradient Boosting | 0.821 | 0.825 | 0.681 | 0.746 |
| KNN | 0.816 | 0.800 | 0.696 | 0.744 |
| Baseline | 0.615 | 0.000 | 0.000 | 0.000 |

Порог F1 > 0.70 прошли все пять моделей. Лучшей выбран Random Forest: по кросс-валидации он лучший и самый стабильный. Самые важные признаки - пол и обращение, затем класс и цена билета. Чаще всего модель ошибается на мужчинах 1-го класса и женщинах 3-го класса.

## Соревнование Kaggle

В данных соревнования нет имён, поэтому модель для него строится без Title (раздел 19 ноутбука): Random Forest на 7 исходных признаках и FamilySize, обучен на всех 891 пассажирах, порог 0.5 выбран по кросс-валидации. Прогноз лежит в submission.csv. Файлы соревнования (train.csv, test.csv, sample_submission.csv) нужно скачать со страницы соревнования и положить в папку data/kaggle.

## Запуск

Нужны numpy, pandas, matplotlib, seaborn, joblib и scikit-learn (версия 1.4 или новее). Ноутбук запускается целиком через Run All (около 2-3 минут). Обученная модель сохраняется в model.joblib, посылка для Kaggle - в submission.csv.
