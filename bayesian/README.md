# Лабораторная работа 4. Байесовская сеть

Байесовская сеть по данным опроса разработчиков Stack Overflow 2026: что связано с зарплатой разработчика и с его отношением к AI-инструментам. Задание лежит в lab04.pdf, решение в ноутбуке lab04_bayesian_network.ipynb.

## Данные

[Stack Overflow Developer Survey 2026](https://survey.stackoverflow.co/2026) - ежегодный опрос разработчиков, 30 903 анкеты. В data/survey_results_2026.csv лежат только 11 столбцов, которые используются в работе (полный файл весит около 120 МБ). Если файла нет, ноутбук скачает его сам из [архива опроса](https://github.com/StackExchange/Survey/tree/main/packages/archive/2026).

Лицензия данных - Open Database License (ODbL) 1.0, содержимое ячеек - Database Contents License (DbCL) 1.0. Источник: Stack Overflow Developer Survey, Stack Exchange Inc.

В сеть вошли 10 525 человек, которые работают по найму и указали зарплату.

## Сеть

7 вершин: регион (страны сгруппированы по классификации Всемирного банка), возраст, опыт работы, изучение AI, отношение к AI, зарплата (терцили) и удовлетворённость работой. 12 рёбер, для каждого объяснено, почему есть зависимость и почему выбрано такое направление. Библиотека - pgmpy.

## Что сделано

- подготовка данных: пропуски (в том числе пропуски, которые возникают из-за логики анкеты), ошибочные значения, дискретизация, проверка достаточности наблюдений
- четыре вопроса к сети, сформулированные до её построения, граф с обоснованием рёбер и списком рёбер, которых в графе нет
- оценка таблиц условных вероятностей (MLE), сверка с данными, сравнение со сглаживанием
- ответы на вопросы через вероятностный вывод с проверкой по данным, эксперимент с последовательным добавлением evidence, марковское одеяло зарплаты
- анализ структуры: удаление ребра, эквивалентные по Маркову сети, проверка независимостей графа тестом хи-квадрат
- причинность: какие рёбра можно считать причинными, do-запрос и почему ему нельзя доверять без дополнительных допущений

## Главные результаты

| Вопрос | Результат |
|---|---|
| Связано ли изучение AI с высокой зарплатой? | изучение AI на работе - да, в любом регионе (в США 0.81 против 0.56 у не изучавших); самостоятельное - почти нет |
| Кто лучше относится к AI-инструментам? | опытные разработчики: положительно 0.62 при опыте 20+ лет против 0.45 у новичков |
| Что сильнее связано с удовлетворённостью работой? | отношение к AI (разница 0.17), а не зарплата (0.09) |
| Что известно о человеке с высокой зарплатой? | он из США с вероятностью 0.57, а если это новичок - 0.84 (эффект объяснения) |

Это связи, а не доказанные причины, подробнее - в разделе 10 ноутбука.

## Запуск

Нужны numpy, pandas, matplotlib, seaborn, networkx и pgmpy (версия 1.1.2 или новее). Ноутбук запускается целиком через Run All, выполнение занимает меньше минуты.
